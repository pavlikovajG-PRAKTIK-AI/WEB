# WEB
https://pavlikovajg-praktik-ai.github.io/WEB/

Veřejné stránky ke sdílení — pracovní listy a podklady pro kolegy z PF UJEP.

Publikováno přes GitHub Pages z větve `main`, kořen repozitáře.

- `index.html`, `en.html` — rozcestník, nejnovější odkazy nahoře
- `style.css` — společný styl všech nových stránek
- `zpetna-vazba/` — formulář „Co potřebujete" pro ambasadory kateder; `vyhodnoceni.html` je pracovní nástroj pro JP a není nikde odkázaný
- `2026_10_01_gift/` — pracovní list Test do Moodlu ve formátu GIFT (CZ, EN, obě verze k tisku)
- `pracovni-list/` — Gem pro vaši katedru (formulář, návod, test)

Každý pracovní list má v názvu složky i souborů ke stažení datum ve tvaru `YYYY_MM_DD_`,
a to datum měsíce, do kterého materiál patří. Všechny soubory k jednomu tématu nesou
stejné datum. Zářijový `pracovni-list/` konvenci zatím nesplňuje, přejmenuje se po 2. 10.

Na repu nesmí být žádné soukromé ani zneužitelné údaje.

Zdroje a needitované verze: `Desktop\Jana\_AI_APPS\Gem_DiplomkyBakalarky`.
